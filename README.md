# S8戦略 自動最適化ツール

**チャートを見ないFX**── 高金利通貨の買いと低金利通貨の売りを組み合わせて「円ニュートラル（βゼロ）」なポートフォリオを自動設計し、スワップ収益だけを静かに積み上げる戦略ツールです。

---

## S8戦略とは

FXのキャリートレード（金利差狙い）をより洗練させた戦略です。

### 基本構造

| バスケット | 通貨 | 目的 |
|-----------|------|------|
| 買い（高金利） | MXN・ZAR・PLN・TRY・CZK・HUF | スワップ収益を受け取る |
| 売り（低金利） | USD・CHF・EUR | スワップを支払うが、円の動きをヘッジする |

買いと売りの比率を数学的に調整することで、**円高・円安どちらに動いてもポートフォリオ全体の損益がほぼゼロ**になるように設計します（円ベータ ≈ 0）。残るのは毎日積み上がる金利差（スワップ）のみ。

### なぜ多通貨に分散するのか

TRY/JPY（トルコリラ円）のようにスワップは高いが長期的に通貨価値が下落する通貨を単体で持つと、スワップで得た収益を為替損失が上回るリスクがあります（2021年12月暴落で-100万円超の実例）。多通貨に分散することで、個々の通貨変動が互いに打ち消し合い、ポートフォリオ全体のボラティリティを大幅に低減します。

### S6 → S8 の進化

| バージョン | 特徴 |
|-----------|------|
| S6 | TRY（トルコリラ）をポートフォリオから除外。安全重視。 |
| S8 | TRYを10〜20%以内に制限しつつ採用。シャープレシオ・カルマーレシオによる自動最適化でTRYの「入れすぎ」をシステムが防ぐ。 |

旧版はスワップ最大化 = TRYを最大限入れる という欲望に流されがちでしたが、S8ではリスク調整後リターンを評価指標にすることで、システムが適切な配分を自動判断します。

## アプリの機能

### 最適化モード

| モード | スコア計算式 | 用途 |
|--------|-------------|------|
| **シャープレシオ最大**（推奨） | `シャープ + カルマー重み × カルマー` | リスク調整後リターンを重視 |
| スワップ最大（旧方式） | `スワップ年率収益率 + カルマー重み × カルマー` | 収益額を重視したい場合 |
| カスタム加重 | `(スワップ・シャープ・カルマー)の加重平均` | 比率を自由に設定 |

- **シャープレシオ**：(平均日次損益 / 日次損益の標準偏差) × √252　→「どれだけ稼いだか ÷ どれだけブレたか」
- **カルマーレシオ**：年率リターン ÷ 最大ドローダウン　→「じわじわ下がり続ける通貨は自動的に低評価」

### リスク制御

- **β（円ベータ）フィルタ**：ポートフォリオ全体のβが許容範囲（推奨 ±0.05）を超える組み合わせを除外
- **相関フィルタ**：買いと売りのバスケットが十分に相関していない組み合わせを除外
- **通貨比率制限**：TRY/MXN/ZARの上限・下限を個別に設定可能

### 出力

- **注文レシピ**：採用プランの推奨ロット数を自動計算（ブローカーのlot単位を要設定）
- **バックテスト**：過去1〜3年の損益推移・スワップ積み上がりをグラフ表示
- **リスク指標**：シャープレシオ・カルマーレシオ・ポートフォリオ標準偏差

## 使い方

### デモモード（パスワード不要）

通貨が2種類に制限されますが、戦略の動作確認・バックテスト閲覧が可能です。

### フルモード（パスワード必要）

全通貨解放・TRY比率制御など全機能を利用できます。パスワードは別途配布しています。

### 推奨設定

```
レバレッジ：16.66倍（証拠金維持率 150% 相当）
許容β：±0.05
最低相関係数：0.80
最適化期間：直近1年（推奨）
再計算タイミング：2〜3か月に1回（TRY組み入れ時は毎月）
```

### ポートフォリオ調整のタイミング

- ポジション全体のβが ±0.05 を超えてきたとき
- 評価損益が自己資金の ±5% を超えてきたとき

## ローカル実行

```bash
# 依存パッケージをインストール
pip install -r requirements.txt

# パスワードを環境変数にセット（未設定の場合は常にデモモード）
export APP_PASSWORD="your_password"

# 起動
streamlit run app.py
```
